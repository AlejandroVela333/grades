# Grades - Actividad 7

Aplicación web desarrollada con Laravel 7 para administrar materias y sus actividades evaluables. El sistema permite registrar, consultar, actualizar y eliminar materias, además de gestionar el tipo, la calificación y la fecha de las actividades asociadas a cada materia.

La documentación completa de la actividad se encuentra en [docs/ACTIVIDAD_7.md](docs/ACTIVIDAD_7.md).

Las capturas del funcionamiento y las verificaciones técnicas están disponibles en [docs/evidencias/](docs/evidencias/).

## Funcionalidades principales

- CRUD de materias.
- Registro, edición y eliminación de actividades evaluables.
- Relación de una materia con múltiples actividades.
- Validación de los datos recibidos por los formularios.
- Pruebas automatizadas del flujo CRUD y de la integridad de la relación.

## Tecnologías

- PHP 7.4.29
- Laravel 7.30.7
- MySQL/MariaDB
- Bootstrap 4.6.2
- PHPUnit 9.6.38
